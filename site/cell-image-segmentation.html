Title

Cell image segmentation

README lines 1–1

Question

Can cells be segmented reliably in a public microscopy image set? This experiment addresses nuclei, using public fluorescence images and reference instance masks. On this held-out subset, both methods exceed the prespecified foreground Dice target. Instance separation remains imperfect, and the experiment does not establish reliability on other microscopy data.

README lines 5–9

Results

Scores are macro averages over 12 held-out images containing 392 reference nuclei, evaluated at native resolution.

README lines 44–45

Limitations

Whole-cell membrane/cytoplasm segmentation: not done. Labels are nuclei.
