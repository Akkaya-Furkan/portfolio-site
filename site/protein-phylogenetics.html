README lines 1–1

Question

Does the tree topology of a protein family agree with known taxonomy?

README lines 7–7

Results

The topology agrees with 2 of 3 sampled order splits. Carnivora is not an exclusive group in this tree; this is retained as a negative result.

README lines 44–45

Limitations

This is a single mitochondrial protein and a deliberately small sample. It is not a species-tree estimate, and order-level agreement does not imply correct relationships within an order.
