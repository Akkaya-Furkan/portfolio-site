README lines 1–1

Question

Can a small multi-user application record experiments with authentication and attachments, while keeping sample-level measurements searchable, exportable and persistent? The one-day implementation boundary and numerical acceptance targets are in docs/SCOPE.md.

README lines 8–11

Results

The demo verifier starts a loopback HTTP server, logs into both accounts, exercises search/export/download, stops the server and starts a fresh app against the same SQLite file. CSV labels, values, units and dates match the database. The downloaded attachment matches all 76 bytes, with SHA-256 2dc211949646a98eef6ac24b0d88d44075d004306df01b8362af6c6f6d727fdc. Duplicate seeding is refused and the stored record counts remain unchanged.
