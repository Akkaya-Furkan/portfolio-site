Title

Multi-endpoint ADMET — does multitask learning help?

README lines 1–1

Question

Does a shared molecular representation improve aqueous solubility, Caco-2 permeability and CYP2D6 inhibition predictions compared with independent single-task models?

README lines 5–7

Results

Intervals are two-sided paired t intervals with Bonferroni correction across three endpoints (per-interval confidence 98.3333%, family alpha 0.05). The predeclared practical threshold is 5% relative MAE reduction or 0.02 absolute AP increase, alongside an interval strictly above zero. The evidence supports 0/3 endpoint-level improvement claims. This is insufficient evidence of benefit, rather than proof that the approaches are equivalent.

README lines 57–62

Limitations

Repeated scaffold splits / split-level uncertainty: not done. Seed intervals describe training randomness conditional on one split. Five differences provide limited support for the t approximation.
