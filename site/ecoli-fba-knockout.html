Title

E. coli single-gene knockout screen

README lines 1–1

Question

Which single-gene deletions prevent growth in the E. coli core metabolic model, and how well does genome-scale iJO1366 essentiality agree with Keio knockout phenotypes on aerobic glucose minimal medium?

README lines 5–5

Results

The core model's lethal genes are gltA (b0720), icd (b1136), gapA (b1779), ptsH (b2415), ptsI (b2416), eno (b2779), and pgk (b2926). The ptsH and ptsI deletions are infeasible under fixed maintenance; the other 135 core solves are optimal. All 1367 iJO1366 solves are optimal.

README lines 43–43

Limitations

The core model covers only a small metabolic network. Experimental essentiality scoring is performed only on iJO1366, not on the core model.
