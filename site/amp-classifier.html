Results

Random splitting overstates ROC-AUC by about 0.065 (secreted peptides) and 0.04 (fragments) compared to the purged split.

README lines 40–40

Limitations

Negative set choice inflates performance and cannot be removed. Both negative sets are assumed inactive (non-antimicrobial annotation in Swiss-Prot), not assayed. They differ from AMPs in origin and processing, so a classifier may partly learn "database/annotation type". Fragments are not real peptides; secreted peptides are few (1,279 after matching) and hard to match on every property. Performance against experimentally confirmed inactive peptides is not measured (not done).

README lines 55–58

Question

Can antimicrobial activity be predicted from sequence features alone, and how much of the apparent accuracy survives once train and test peptides are properly separated by sequence similarity?
