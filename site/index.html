P02README evidence

EGFR resistance — does MM-GBSA rank better than docking?

Does end-point free energy (MM-GBSA) rank the EGFR resistance pattern for osimertinib better than docking scores (egfr-resistance-docking)?

Reported result

Both methods put T790M first. MM-GBSA resolves T790M from the triple-mutant construct: −15.0 kcal/mol (95 % CI −23.8 … −6.3; Welch p = 0.01; n = 3 seeds per genotype). About two thirds of that gap (−10.1) is van der Waals.

Scope & limitation

1. Starting-structure bias. WT starts from a gefitinib-bound crystal, T790M and the triple construct from structures with the co-crystal ligand YY3; osimertinib was docked into all three. Pocket shape differs by construction, which can favour the mutants and contributes to the WT pose drift. 2. n = 3 seeds from one equilibrated state per genotype: SDs underestimate structural uncertainty; the T790M–WT comparison is under-powered. 3. WT not converged at 20 ns (seed 3 drifting, seed 1 settled in a displaced pose). A longer WT run from several starting poses is the remaining open item. 4. Osimertinib binds C797 covalently; everything here is non-covalent, so C797S resistance is not expected to appear in these energies. 5. No entropy; GB/PB disagree by ≈ 60 kcal/mol in absolute terms; only rankings are used. 6. Per-residue decomposition uses 25 frames per run and three seeds; an earlier single-seed version (one seed vs an unequilibrated WT) suggested residue 797 as the largest contributor (−3.4); with three seeds it is −1.66 ± 0.85 and not resolved, and residue 718 leads.

P13README evidence

How well does pLDDT predict structural accuracy?

pLDDT is the per-residue confidence reported by AlphaFold and ESMFold. Does it track the actual accuracy of a model against an experimental structure, i.e. is it calibrated (a residue with pLDDT 80 is ~0.80 correct)? Does that hold for structures the predictors could not have seen, and for regions that are disordered?

Reported result

Both predictors are close to the diagonal: ECE = 0.016 (95 % CI 0.013–0.022; 36,467 residues) for ESMFold and 0.012 (0.004–0.024; 30,196 residues) for AlphaFold DB.

Scope & limitation

Accuracy reference is a single crystal structure. lDDT against one X-ray model penalises genuine flexibility and crystal-packing differences; lDDT is computed on Cα atoms only (not all-atom lDDT), residues are scored equally rather than contact-weighted, and chains were evaluated alone (no ligand, partner or oligomer context).

P24README evidence

Multi-endpoint ADMET — does multitask learning help?

Does a shared molecular representation improve aqueous solubility, Caco-2 permeability and CYP2D6 inhibition predictions compared with independent single-task models?

Reported result

Intervals are two-sided paired t intervals with Bonferroni correction across three endpoints (per-interval confidence 98.3333%, family alpha 0.05). The predeclared practical threshold is 5% relative MAE reduction or 0.02 absolute AP increase, alongside an interval strictly above zero. The evidence supports 0/3 endpoint-level improvement claims. This is insufficient evidence of benefit, rather than proof that the approaches are equivalent.

Scope & limitation

Repeated scaffold splits / split-level uncertainty: not done. Seed intervals describe training randomness conditional on one split. Five differences provide limited support for the t approximation.

P26README evidence

16S microbiome — community differences

Do microbial communities differ among body sites in a public 16S rRNA dataset?

Reported result

PERMANOVA attributes 45.84% of distance variation to body-site grouping in the complete-visit subset. The exact restricted test is not significant at 0.05; the small independent subject count limits inference. Alpha tests also do not pass the threshold after correction. The dispersion diagnostic does not reject, which is not proof of equal dispersion.

Scope & limitation

Only 2 independent participants; repeated visits do not increase independent biological replication. Whole-trajectory exchangeability is an assumption, not a randomized design. Exact p-values have a coarse reference distribution. No population-level or causal conclusion is supported.

P28README evidence

Parameterised measurement reports with Quarto

Can a validated measurement CSV become a reproducible, parameterised report with one command?

Reported result

The deterministic example contains 30 synthetic observations. The committed reference report and comparison report each select 15 observations and contain 5 dose summaries. Download an HTML file and open it locally; GitHub's file viewer displays source. Each report has a companion JSON file in the same directory. The committed reference PDF and JSON sidecar select 15 observations across 5 doses. Local pdfinfo measured 2 A4 pages and 47,586 bytes, produced by Typst 0.15.1; both pages were rendered to PNG and visually inspected. PDF bytes can vary with creation metadata and platform fonts.

Scope & limitation

This is descriptive reporting with arbitrary units. It performs no curve fitting, hypothesis testing, confidence interval calculation, or potency estimation. Error bars show sample standard deviation. A singleton has undefined SD and is displayed as NA. Values shown in the report are rounded; JSON retains numerical precision. The CSV fingerprint identifies the input bytes but does not establish experimental provenance. Finite inputs whose statistics overflow are rejected. The environment is pinned for Python 3.11 on Linux; HTML and Typst PDF rendering were validated locally on Linux; other platforms have not been validated. The XeLaTeX/TinyTeX route is not implemented or tested. The report/sidecar pair is rolled back on ordinary write failures but is not a crash-atomic multi-file transaction. Very large input files and interactive dashboards are outside scope.
