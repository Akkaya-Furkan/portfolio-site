Title

Variant annotation pipeline

README lines 1–1

Question

Can a public VCF be annotated and filtered reproducibly with a small local resource, without downloading a VEP or SnpEff database?

README lines 5–6

Results

The committed run covers chromosome 1, positions 66,926–939,279 (1-based), and produced 300 annotated rows from 300 unique input alleles. All 300/300 matched the local snapshot; 0 were unmatched. There are 0 missing gene annotations and 3 missing molecular-consequence annotations.

README lines 87–90

Limitations

Not done: VEP/SnpEff execution or de novo transcript consequence prediction. Molecular consequences and gene labels are copied from the bundled ClinVar resource.
