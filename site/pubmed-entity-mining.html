Title

PubMed text mining: target and compound mentions

README lines 1–1

Question

Can target and compound mentions be extracted automatically from PubMed abstracts, and which entities occur most often in a small sample across publication years?

README lines 9–10

Results

The download contains 60/60 requested records, 60 unique PMIDs and 59 non-empty abstracts. One record passed the remote hasabstract query but has no abstract in the returned XML; it is retained transparently. The extractor produced 527 mention rows, 164 distinct document–entity pairs, and 20 distinct canonical entities.

README lines 95–99

Limitations

Human-labelled evaluation sample: not done. Independent human review and inter-annotator agreement: not done. The implementing assistant also authored labels, so evaluator dependence and annotation bias remain. The artifact-level deliverables (extraction table, accuracy calculation, figures and write-up) are present, but the human-annotation part of the original scope is not fulfilled.
